## What is VibeCoder Heretic?

VibeCoder Heretic lets you delegate 90% of development to AI agents. The whole developer workflow — from coding to code review — is managed by agents. Full workflow with PRs, Kanban boards, and real-time visibility. Your code stays on your servers. Forever.

---

## Project Structure

| Directory | Description |
|-----------|-------------|
| [`cli/`](cli/) | CLI tool built with Bun and TypeScript. Manages agent profiles, Docker containers, project initialization, and self-updates. Compiles to a native executable. See [cli/README.md](cli/README.md) for details. |
| `docs/` | Project documentation |
| `scripts/` | Development helper scripts (git hooks setup) |
